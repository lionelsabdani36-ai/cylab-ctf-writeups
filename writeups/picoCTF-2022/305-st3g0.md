## Teori & Akar Kerentanan (Root Cause Theory)

1. **Prinsip Steganografi Least Significant Bit (LSB):**
   - Dalam ruang warna digital 24-bit/32-bit (RGB/RGBA), setiap komponen warna diwakili oleh 1 bita (8 bit, bernilai $0\text{-}255$).
   - Mengubah bit paling tidak signifikan (*least significant bit* / LSB, posisi $2^0$) pada nilai warna hanya mengubah intensitas cahaya sebesar $\pm 1$ level dari 256 tingkatan. Perubahan ini secara visual imperseptibel (tidak dapat dideteksi oleh mata manusia).
   - Penyerang atau perancang tantangan memanfaatkan LSB kanal warna $R$, $G$, dan $B$ untuk menginjeksi bit-bit pesan rahasia secara berurutan (*sequential channel embedding*).

2. **Arsitektur Dekompresi & Rekonstruksi Baris PNG (RFC 2083):**
   - Berkas PNG membagi data piksel ke dalam blok IDAT terkompresi Deflate (`zlib`).
   - Setiap baris pemindaian (*scanline*) diawali oleh 1 bita penanda filter (*filter byte*):
     - `0` = None
     - `1` = Sub (rekonstruksi terhadap piksel sebelah kiri)
     - `2` = Up (rekonstruksi terhadap piksel baris sebelumnya)
     - `3` = Average (rata-rata kiri dan atas)
     - `4` = Paeth (prediktor linear Paeth)
   - Sebelum nilai bit LSB dapat dibaca secara akurat, seluruh scanline harus melalui proses defiltering untuk mengembalikan nilai asli komponen bita warna ($R, G, B, A$).
   - Pola ekstraksi `b1,rgb,lsb,xy` membaca bit LSB dari kanal $R$, dilanjutkan $G$, lalu $B$ untuk setiap piksel secara horizontal per baris ($x$ lalu $y$).

1. **Pengunduhan Artefak Berkas:**


2. **Inspeksi Karakteristik Citra:**
   Gunakan utilitas `file` dan `pngcheck` untuk memverifikasi struktur dasar:
   ```bash
   file academy.flag.png
   ```
   Keluaran:
   ```text
   academy.flag.png: PNG image data, 661 x 181, 8-bit/color RGBA, non-interlaced
   ```

3. **Ekstraksi Steganografi LSB Menggunakan `zsteg`:**
   Jalankan penganalisis LSB `zsteg`:
   ```bash
   zsteg -a academy.flag.png
   ```
   Keluaran mendeteksi string teks pada kombinasi `b1,rgb,lsb,xy`:
   ```text
   b1,rgb,lsb,xy       .. text: "academy{7h3r3_15_n0_5p00n_7e497237}$t3g0"
   ```
   Perhatikan akhiran `$t3g0` yang tepat bersesuaian dengan petunjuk resmi tantangan.

4. **Ekstraksi Mandiri via Python (Zero-Dependency Engine):**
   Menerapkan algoritma defiltering RFC 2083 dan unpacking bita LSB secara deterministik:
   ```python

   decomp = zlib.decompress(idat_bytes)
   # 2. Rekonstruksi scanline (Paeth/Sub/Up/Average)
   # 3. Ekstraksi bit 0 pada kanal R, G, B per piksel
   # 4. Rekonstruksi byte: val |= (bit << (7 - j))
   ```
   Menghasilkan string token bersih:

## Takeaway Kompetensi LKS & Mitigasi Defensif

- **Kompetensi Inti LKS Cyber Security:** Dalam kompetisi forensik LKS, steganografi citra digital adalah salah satu uji kompetensi wajib. Peserta dituntut mampu mengoperasikan utilitas otomatis (`zsteg`, `stegsolve`, `exiftool`) serta memahami struktur internal bita piksel bila berhadapan dengan variasi steganografi kustom atau non-standar.
- **Mitigasi Defensif (Pencegahan Eksfiltrasi Data via Citra):**
  1. *Sanitasi & Rekompresi Citra pada Media Gateway:* Sistem portal berkas atau web aplikasi publik harus menerapkan normalisasi citra (misalnya merender ulang citra melalui antarmuka grafis atau konversi ke format kompresi lossy seperti JPEG terstandar) guna merusak struktur LSB yang mungkin disisipi data rahasia (*covert channel*).
  2. *Deteksi Anomali Statistik (Steganalisis):* Implementasikan sensor pengawas saluran keluar (*egress monitoring*) yang melakukan pengujian $\chi^2$ (*chi-square analysis*) terhadap distribusi nilai LSB citra untuk mendeteksi pembawa muatan tersembunyi.
