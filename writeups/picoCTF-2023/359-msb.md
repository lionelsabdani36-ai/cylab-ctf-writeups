## Problem Statement & Scope
Diberikan sebuah berkas gambar lukisan tradisional Jepang format PNG 24-bit (`Ninja-and-Prince-Genji-Ukiyoe-Utagawa-Kunisada.flag.png`) beresolusi 1074x1500 piksel. Uji statistik standar untuk Least Significant Bit (LSB) steganografi menunjukkan hasil negatif. Namun, terdapat artefak visual mencolok pada gambar yang mengindikasikan adanya payload data tersembunyi pada bidang bit (*bitplane*) yang tidak lazim.

---

## Teori & Akar Kerentanan (Root Cause Theory)
1. **Manipulasi Bitplane Tingkat Tinggi (MSB Steganography):** Teknik steganografi spasial umumnya menyisipkan data pada bit paling tidak signifikan (LSB / bit 0) agar perubahan intensitas warna tidak terdeteksi oleh mata manusia. Pada tantangan ini, payload justru disematkan pada Most Significant Bit (MSB / bit 7) dari setiap kanal warna (Red, Green, Blue). Pengubahan nilai bit 7 secara langsung mempengaruhi kontras dan saturasi warna piksel sebesar 128 unit intensitas, menciptakan pola artefak visual pada citra penampung (*cover image*).
2. **Karakteristik Kompresi dan Filtering PNG (RFC 2083):** Format Portable Network Graphics (PNG) menerapkan proses filtering prediktif pada setiap baris pemindaian (*scanline*) sebelum dikompresi dengan DEFLATE/zlib (chunk IDAT). Jenis filter per baris meliputi None (0), Sub (1), Up (2), Average (3), dan Paeth (4). Untuk mengekstrak nilai bit mentah dari piksel secara akurat tanpa dependensi eksternal, analis harus merekonstruksi proses *defiltering* byte per byte sesuai spesifikasi RFC 2083.
3. **Serialisasi Aliran Bit ke Byte:** Setelah seluruh kanal warna (RGB) didefilter, bit ke-7 dari setiap byte kanal diekstraksi secara sekuensial dan dirangkai kembali ke dalam aliran byte (8 bit per byte, MSB-first) untuk membentuk teks rahasia yang memuat flag.

## Rekonstruksi Eksploitasi Step-by-Step
1. Analisis awal citra digital:
   ```bash
   file Ninja-and-Prince-Genji-Ukiyoe-Utagawa-Kunisada.flag.png
   # Ninja-and-Prince-Genji-Ukiyoe-Utagawa-Kunisada.flag.png: PNG image data, 1074 x 1500, 8-bit/color RGB, non-interlaced
   ```
2. Pengujian steganografi standar (LSB):
   Pengujian menggunakan alat seperti `zsteg` menunjukkan bahwa bidang bit LSB bersih dari payload atau hanya berisi derau acak.
3. Rekonstruksi pemindaian PNG dan defiltering berbasis Python:
   - Baca chunk `IHDR` untuk mendapatkan dimensi $1074 \times 1500$ piksel, kedalaman bit 8, dan tipe warna RGB (3 byte per piksel).
   - Gabungkan seluruh chunk `IDAT` dan dekompresi data menggunakan `zlib.decompress()`.
   - Lakukan pembalikan filter (defiltering) untuk tipe filter None, Sub, Up, Average, dan Paeth baris demi baris:
     ```python
     # Rumus prediktor Paeth sesuai RFC 2083
     def paeth(a, b, c):
         p = a + b - c
         pa, pb, pc = abs(p - a), abs(p - b), abs(p - c)
         if pa <= pb and pa <= pc: return a
         elif pb <= pc: return b
         else: return c
     ```
4. Ekstraksi bit ke-7 (MSB) dari setiap kanal byte:
   ```python
   bits = [(byte >> 7) & 1 for byte in recon]
   extracted = bytearray()
   for i in range(0, len(bits) - 7, 8):
       byte_val = 0
       for j in range(8):
           byte_val = (byte_val << 1) | bits[i + j]
       extracted.append(byte_val)
   ```
5. Pencarian ekspresi reguler flag pada aliran data hasil ekstraksi:
   ```python
   import re
   match = re.search(rb"(?:academy|picoCTF|CTF)\{[^\}]+\}", bytes(extracted))
   print(match.group(0).decode())
   ```


## Takeaway Kompetensi LKS & Mitigasi Defensif
- **Pemahaman Struktur Internal Format Berkas Citra (RFC 2083):** Pada kompetisi LKS Cyber Security bidang Forensik Digital, peserta tidak boleh hanya bergantung pada tool otomatis hitam (*black-box tools*) seperti `zsteg` atau `binwalk`. Kemampuan mem-parsing struktur biner format citra dan memahami mekanisme filtering memungkinkan analis membongkar steganografi non-konvensional seperti MSB, parity embedding, atau modifikasi koefisien DCT.
- **Deteksi Anomali Bitplane dan Pencegahan Eksfiltrasi Data:** Dari sisi mitigasi defensif (DLP / Data Loss Prevention), kanal citra yang diunggah ke portal publik atau ditransmisikan keluar jaringan harus dianalisis menggunakan filter dispersi entropi atau dinormalisasi melalui kompresi ulang berulang (*re-encoding / raster stripping*) guna memusnahkan payload tersembunyi tanpa merusak kualitas fungsional citra.
