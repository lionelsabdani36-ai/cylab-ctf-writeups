## Problem Statement & Scope
Diberikan berkas tersandi `ciphertext` dan skrip enkripsi Python `convert.py` yang mengimplementasikan *Custom Cyclical Cipher* (C3). Peserta diminta membalik alur enkripsi untuk memulihkan pesan asli, mengeksekusi logika lanjutan, dan membungkus hasil akhir ke format resmi platform `academy{...}`.

---

## Teori & Akar Kerentanan (Root Cause Theory)
1. **Inversi Cipher Berulang (Cyclical Running-Key Inversion):**
   Skrip enkripsi memetakan karakter teks terang dari alfabet indeks `lookup1` (40 karakter) ke alfabet sandi `lookup2` (40 karakter) menggunakan selisih modular terhadap indeks karakter sebelumnya:
   $$\Delta_i = (cur_i - prev_i) \pmod{40}, \quad out_i = \text{lookup2}[\Delta_i]$$
   di mana $prev_0 = 0$ dan $prev_{i} = cur_{i-1}$. Karena operasi penjumlahan dan modulo memiliki invers aditif langsung pada ring $\mathbb{Z}_{40}$:
   $$cur_i = (\text{lookup2.index}(out_i) + prev_i) \pmod{40}$$
   Pesan asli dapat didekripsi secara linear dan deterministik $\mathcal{O}(N)$ tanpa kehilangan informasi.
2. **Tahap Dua: Logika Skrip Swasaji (Self-Input / Quine-like Evaluation):**
   Teks terang hasil pembalikan C3 ternyata merupakan skrip Python 2 yang memproses dirinya sendiri (*#selfinput*). Skrip tersebut mengindeks karakter pada posisi kubik $i = b^3$ untuk $b = 1, 2, 3, \dots$:
   - $b=1 \implies 1^3 = 1 \implies \text{chars}[1] = \text{'a'}$
   - $b=2 \implies 2^3 = 8 \implies \text{chars}[8] = \text{'d'}$
   - $b=3 \implies 3^3 = 27 \implies \text{chars}[27] = \text{'l'}$
   - $b=4 \implies 4^3 = 64 \implies \text{chars}[64] = \text{'i'}$
   - $b=5 \implies 5^3 = 125 \implies \text{chars}[125] = \text{'b'}$
   - $b=6 \implies 6^3 = 216 \implies \text{chars}[216] = \text{'s'}$
   Rangkaian karakter pada indeks kubik tersebut menghasilkan kata `adlibs`.

## Rekonstruksi Eksploitasi Step-by-Step
1. Analisis algoritma `convert.py`:
   ```python
   lookup1 = '\n "#()*+/1:=[]abcdefghijklmnopqrstuvwxyz'
   lookup2 = "ABCDEFGHIJKLMNOPQRSTabcdefghijklmnopqrst"
   ```
2. Buat skrip dekripsi C3 untuk membalik proses enkripsi:
   ```python
   with open('ciphertext', 'r') as f:
       ct = f.read().strip()

   pt = ""
   prev = 0
   for c in ct:
       diff = lookup2.index(c)
       cur = (diff + prev) % 40
       pt += lookup1[cur]
       prev = cur
   ```
3. Evaluasi skrip hasil dekripsi:
   ```python
   chars = pt
   b = 1
   out = []
   for i in range(len(chars)):
       if i == b * b * b:
           out.append(chars[i])
           b += 1
   inner = "".join(out)  # 'adlibs'
   ```
4. Bungkus string dengan format flag resmi:
   $$\text{Flag} = \text{academy\{adlibs\}}$$

## Takeaway Kompetensi LKS & Mitigasi Defensif
- **Larangan Desain Kriptografi Kustom (Don't Roll Your Own Crypto):** C3 adalah representasi cipher substitusi modular polialfabetik sederhana dengan *state* internal rapuh. Pada modul *Defensive Cryptography* di LKS Cyber Security, selalu terapkan algoritma standar industri yang teruji resisten terhadap analisis kriptografi (seperti AES-GCM atau ChaCha20-Poly1305).
- **Integritas dan Validasi Eksekusi Kode Dinamis:** Membiarkan sebuah program memproses dan mengevaluasi kode sumbernya sendiri secara dinamis membuka potensi eksploitasi jika input teks dapat dimanipulasi oleh penyerang (*arbitrary code execution*).
