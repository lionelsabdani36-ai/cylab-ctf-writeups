## Problem Statement & Scope
Diberikan biner ELF dan kode sumber `chall.c` yang mendemonstrasikan alokasi dinamis memori heap. Program mengalokasikan dua blok memori menggunakan fungsi `malloc()`: satu untuk `input_data` (5 byte) dan satu lagi untuk variabel kontrol keamanan `safe_var` (5 byte, berisi string `"bico"`). Peserta ditantang membuktikan bahwa kerentanan buffer overflow tidak hanya terjadi pada stack, melainkan juga dapat dieksploitasi pada heap untuk menimpa nilai `safe_var` dan memenuhi kondisi kemenangan.

---

## Teori & Akar Kerentanan (Root Cause Theory)
1. **Alokasi Heap dan Tata Letak Chunk (glibc malloc):**
   Fungsi `malloc(size)` mengalokasikan blok memori dari area heap proses. Ketika dua alokasi dilakukan secara berurutan:
   ```c
   input_data = malloc(5); // Chunk 1
   safe_var   = malloc(5); // Chunk 2
   ```
   Pengelola memori heap menempatkan `safe_var` pada alamat yang lebih tinggi tepat setelah batas chunk `input_data` (ditambah metadata header chunk glibc).
2. **Ketiadaan Pembatasan Panjang Input (`scanf("%s")`):**
   Fungsi `write_buffer()` membaca input pengguna tanpa batasan batas ukuran:
   ```c
   scanf("%s", input_data);
   ```
   Penentu format `%s` membaca karakter tanpa henti hingga menemukan spasi/karakter baris baru.
3. **Linear Heap Buffer Overflow:**
   Jika pengguna memasukkan string yang lebih panjang dari ukuran kapasitas chunk `input_data` beserta padding perataan memori (*alignment padding* dan *chunk metadata*), byte input berlebih akan meluap (*overflow*) secara linear dan menimpa konten chunk berikutnya, yaitu `safe_var`.
4. **Win Condition:**
   Fungsi `check_win()` membandingkan nilai string `safe_var`:
   ```c
   if (strcmp(safe_var, "bico") != 0) {
       // Cetak flag!
   }
   ```
   Selama byte pertama `safe_var` tidak lagi bernilai `"bico"`, kondisi terpenuhi dan program akan membaca serta mencetak berkas `flag.txt`.

## Takeaway Kompetensi LKS & Mitigasi Defensif
- **Gunakan Fungsi Input Terbatas (Bounded String Input):** Jangan pernah menggunakan `scanf("%s", buf)` atau `gets()`. Gunakan `fgets()` atau tentukan batas lebar maksimum pada format specifier:
  ```c
  // Aman:
  scanf("%4s", input_data); // Membaca maksimal 4 byte + 1 byte null terminator
  ```
- **Pemanfaatan Memory Safety Sanitizer:** Gunakan flag `-fsanitize=address` (ASan) selama proses kompilasi pengujian perangkat lunak. AddressSanitizer secara otomatis mendeteksi heap buffer overflow saat eksekusi dan menghentikan proses sebelum terjadi manipulasi status memori.
