## Problem Statement & Scope
Diberikan berkas disassembly x86 `test.S`. Analis diminta menghitung nilai kembalian (return value) fungsi `asm2(0xb, 0x1a)` saat dipanggil dengan dua argumen bilangan bulat heksadesimal tersebut. Nilai akhir diserahkan dalam format heksadesimal berawalan `0x`.

---

## Teori & Akar Kerentanan (Root Cause Theory)
1. **Konvensi Pemanggilan x86 cdecl (Standard Calling Convention):**
   - Pada arsitektur IA-32 / 32-bit x86, argumen fungsi dilewatkan melalui stack dari kanan ke kiri.
   - Prosedur pembentukan stack frame standar (function prologue):
     ```assembly
     push ebp
     mov  ebp, esp
     sub  esp, 0x10
     ```
   - Tata letak memori relatif terhadap register basis `ebp`:
     - `[ebp]` = pointer basis lama (saved EBP frame)
     - `[ebp+0x4]` = alamat kembali (return address)
     - `[ebp+0x8]` = argumen pertama (`arg1 = 0xb` / 11)
     - `[ebp+0xc]` = argumen kedua (`arg2 = 0x1a` / 26)
     - `[ebp-0x4]` = variabel lokal pertama (`local1`)
     - `[ebp-0x8]` = variabel lokal kedua (`local2`)
2. **Struktur Kontrol Perulangan Assembling (Loop Control Flow):**
   - Instruksi `jmp 0x119c <asm2+31>` melompati tubuh loop dan langsung mengevaluasi batas terminasi pada `[ebp-0x8] <= 0x5ed6` (`jle`).
   - Tubuh loop mengakumulasi nilai:
     - `local1 = local1 + 0x1`
     - `local2 = local2 + 0xe7`
   - Nilai akhir register akumulator `eax` dipindahkan dari `[ebp-0x4]` sebelum pemulihan stack frame (`leave`, `ret`).

---

## Rekonstruksi Eksploitasi Step-by-Step
1. Identifikasi inisialisasi variabel:
   - `local1 = [ebp-0x4] = arg2 = 0x1a` (26 desimal)
   - `local2 = [ebp-0x8] = arg1 = 0xb` (11 desimal)
2. Analisis iterasi matematis:
   - Nilai batas: `0x5ed6` = 24278 desimal.
   - Peningkatan per iterasi: `0xe7` = 231 desimal.
   - Kondisi terminasi terjadi saat `local2 > 24278`.
   - Menghitung jumlah iterasi ($N$):
     $$11 + 231 \times N \le 24278 \implies 231 \times N \le 24267 \implies N = \lfloor 24267 / 231 \rfloor = 105$$
     Karena perbandingan `jle` mengevaluasi inklusif dari iterasi ke-0, total perulangan tubuh loop adalah $105 + 1 = 106$ kali.
3. Menghitung nilai akhir `local1`:
   - `local1 = 26 + 106 = 132` desimal.
   - Konversi 132 ke heksadesimal: $132 = 8 \times 16 + 4 \implies$ `0x84`.
4. Eksekusi skrip solver reproduktif:
   ```bash
   python3 scripts/solve_16_asm2.py
   ```
   Output: `Flag: 0x84`

## Takeaway Kompetensi LKS & Mitigasi Defensif
- **Takeaway LKS:** Penguasaan tracing instruksi tingkat rendah (assembly) tanpa dekompiler tingkat tinggi (seperti Ghidra / IDA Pro) merupakan kompetensi fundamental LKS Cyber Security untuk memahami kalkulasi batas buffer, counter loop, dan kondisi integer overflow.
- **Mitigasi Defensif:** Dalam perancangan biner produksi, kompilasi kode sumber harus menerapkan optimasi loop dan sanitasi batasan numerik (compiler flags `-ftrapv` atau `-fstack-protector-strong`) guna mencegah anomali kontrol alur akibat kalkulasi integer tak terkendali.
