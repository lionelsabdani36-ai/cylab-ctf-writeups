## Analisis Kerentanan & Konsep Teknis
Citra `red.png` tampak sebagai gambar kotak warna merah pekat berukuran 128x128 piksel format RGBA.

Petunjuk tantangan memberikan acuan penting:
1. **Pemeriksaan Metadata (Meta / Facebook):** Chunk teks PNG (`tEXt`) menyertakan puisi dengan akronim vertikal (akrostik):
   - **C**rimson heart...
   - **H**earts flutter...
   - **E**venings glow...
   - **C**herries burst...
   - **K**isses linger...
   - **L**ove deep...
   - **S**carlet leaves...
   - **B**old in every stroke...
   Huruf awal baris membentuk kata: **`CHECK LSB`**.
2. **Kanal Warna ("Red?Ged?Bed?Aed?"):** Mengindikasikan pemanfaatan kanal Red, Green, Blue, dan Alpha (RGBA).
3. **Ekstraksi Least Significant Bit (LSB):** Bit terendah dari setiap byte warna pada koordinat piksel (interleaved RGBA) menyimpan representasi string Base64:
   ```text
   YWNhZGVteXtyM2RfMXNfdGgzX3VsdDFtNHQzX2N1cjNfZjByXzU0ZG4zNTVffQ==
   ```
4. Mendekode Base64 tersebut menghasilkan flag:
   ```text
   academy{r3d_1s_th3_ult1m4t3_cur3_f0r_54dn355_}
   ```

## Tahapan Eksploitasi & Solusi
1. Gunakan alat inspeksi steganografi `zsteg`:
   ```bash
   zsteg red.png
   ```
   Output mendeteksi data tersembunyi pada mode `b1,rgba,lsb,xy`:
   ```text
   b1,rgba,lsb,xy .. text: "YWNhZGVteXtyM2RfMXNfdGgzX3VsdDFtNHQzX2N1cjNfZjByXzU0ZG4zNTVffQ=="
   ```
2. Dekode muatan Base64:
   ```bash
   echo "YWNhZGVteXtyM2RfMXNfdGgzX3VsdDFtNHQzX2N1cjNfZjByXzU0ZG4zNTVffQ==" | base64 -d
   ```
3. Flag yang didapatkan:
   ```text
   academy{r3d_1s_th3_ult1m4t3_cur3_f0r_54dn355_}
   ```

## Pembelajaran Defensif & Mitigasi LKS
- **Penyembunyian Data Spasial (Spatial Domain Steganography):** Manipulasi LSB menghasilkan perubahan nilai warna yang sangat kecil (perbedaan 1 level intensitas) sehingga tidak dapat dibedakan oleh mata manusia (*imperceptible*).
- **Deteksi Steganalisis Chi-Square / Sample Pairs:** Alat steganalisis mendeteksi anomali distribusi nilai ganjil-genap pada histogram citra digital untuk mengungkap keberadaan payload tersembunyi.
