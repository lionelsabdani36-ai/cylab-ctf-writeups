## Problem Statement & Scope

Tantangan ini menyajikan sebuah berkas teks berisi struktur data Python tersandi:
> *"We intercepted a strange list-based payload generated by an algorithm claiming to use quantum scrambling. Can you reverse the transformations and extract the hidden flag?"*

Struktur data input terdiri atas daftar bertingkat (*nested list*) yang memuat representasi string heksadesimal dari setiap karakter flag asli yang telah dipindahkan, disisipi indeks urutan, dan dibungkus dalam sub-array berlapis.

---

## Teori & Akar Kerentanan (Root Cause Theory)

1. **Reversible Deterministic Transposition (CWE-327):**
   Algoritma yang disebut sebagai *quantum scrambler* sebenarnya hanyalah skema transposisi dan pembungkusan data deterministik. Setiap karakter teks jelas $c_i$ dikonversi menjadi representasi heksadesimal `hex(ord(c_i))`. Karena tidak ada penambahan entropi kriptografis semu, operasi bitwise XOR satu arah, atau kompresi destruktif, relasi antara data masukan dan keluaran adalah pemetaan satu-satu (*bijection*).

2. **Pola Artefak Indeks Deterministik:**
   Algoritma penyandian membungkus elemen dalam bentuk:
   ```python
   scrambled.append([item[0], [hex(i)]])
   ```
   Indeks posisi $i$ disematkan berdampingan dengan byte karakter asli. Dengan membedakan format penyimpanan dan menyaring nilai heksadesimal ke dalam batas karakter ASCII tercetak ($32 \le \text{val} \le 126$), informasi karakter asli dapat dipulihkan secara deterministik.

---

## Rekonstruksi Eksploitasi Step-by-Step

1. **Parsing Struktur Data Masukan:**
   Membaca berkas keluaran dan mengurai string representasi objek menggunakan parser aman AST Python (`ast.literal_eval`).
2. **Penelusuran Elemen Bertingkat (Tree Traversal):**
   Melakukan iterasi rekursif atau traversal datar pada struktur list bersarang.
3. **Penyaringan Byte ASCII Valid:**
   Untuk setiap elemen string berawalan `0x`:
   - Konversi nilai heksadesimal ke representasi integer: $\text{val} = \text{int}(s, 16)$.
   - Periksa apakah $\text{val}$ berada dalam jangkauan karakter ASCII tercetak.
   - Abaikan elemen penanda indeks yang tidak merepresentasikan komponen string flag.
4. **Rekonstruksi Teks Jelas:**
   Menggabungkan karakter-karakter yang telah dipulihkan (`chr(val)`) secara berurutan hingga menghasilkan token flag utuh.

## Remediasi & Mitigasi (Perspektif Defensive LKS)

1. **Gunakan Algoritma Enkripsi Standar Teruji (NIST Standard):**
   Jangan pernah menciptakan algoritma penyandian sendiri (*rolling your own crypto*). Terapkan skema kriptografi simetris terautentikasi modern seperti **AES-256-GCM** atau **ChaCha20-Poly1305** yang menjamin kerahasiaan (*confidentiality*) dan integritas (*authenticity*).
2. **Terapkan Manajemen Kunci Kriptografi Aman:**
   Gunakan fungsi derivasi kunci yang kuat seperti **HKDF** atau **PBKDF2/Argon2** dengan *salt* acak unik berukuran minimal 128-bit untuk mencegah serangan *rainbow table* dan analisis statistik permutasi.
