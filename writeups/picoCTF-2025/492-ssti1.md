## Teori & Akar Kerentanan (Root Cause Theory)

1. **Server-Side Template Injection (CWE-1336 / PEP 3333):**
   Kerentanan SSTI terjadi ketika aplikasi menggabungkan masukan pengguna secara langsung ke dalam string template sebelum proses kompilasi template dijalankan:
   ```python
   # Kerentanan fatal: interpolasi string mentah
   template = f"<h1>{user_content}</h1>"
   return render_template_string(template)
   ```
   Pada arsitektur template Jinja2, karakter kurung kurawal ganda `{{ ... }}` menandakan blok ekspresi Python yang harus dievaluasi saat waktu render (*runtime evaluation*).

2. **Eskalasi Konteks Template ke Eksekusi Perintah Sistem (CWE-94):**
   Meskipun Jinja2 tidak mengekspos fungsi berbahaya seperti `os.system` secara langsung dalam konteks global dasar, objek-objek fungsi pembantu bawaan seperti `lipsum`, `cycler`, atau `joiner` tetap mempertahankan referensi ke modul global Python tempat objek tersebut didefinisikan:
   - `lipsum.__globals__` mengembalikan kamus variabel global modul `jinja2.utils`.
   - Modul ini mengimpor pustaka standar `os`.
   - Melalui referensi `lipsum.__globals__['os']`, penyerang memperoleh akses penuh ke fungsi `popen()`, memungkinkan eksekusi perintah shell arbitrari dengan hak akses proses web server.

## Rekonstruksi Eksploitasi Step-by-Step

1. **Deteksi Kerentanan SSTI (Probing Sintaks):**
   Kirimkan permintaan HTTP POST dengan parameter `content` berisi ekspresi aritmatika:
   ```bash
   curl -s -X POST "http://target-instance/announce" -d "content={{7*7}}"
   ```
   Respons menampilkan nilai `49`:

## Takeaway Kompetensi LKS & Mitigasi Defensif

1. **Larangan Penggunaan `render_template_string` untuk Input Pengguna (CWE-1336):**
   - Jangan pernah menyematkan masukan pengguna mentah ke dalam string template. Selalu gunakan berkas template statis dengan variabel konteks terikat (*parameterized context*):
     ```python
     # Pola Aman:
     return render_template("announce.html", announcement=user_content)
     ```
   - Mesin template akan memperlakukan variabel `announcement` murni sebagai data teks (string literal) dan otomatis mengabaikan tanda kurung kurawal ganda `{{ ... }}`.

2. **Konfigurasi Jinja2 `SandboxedEnvironment` (CWE-94):**
   - Jika pengguna diwajibkan untuk mengedit template secara dinamis, implementasikan `jinja2.sandbox.SandboxedEnvironment` yang memblokir akses ke atribut sensitif seperti `__globals__`, `__mro__`, `__subclasses__`, serta membatasi fungsi bawaan yang dapat dipanggil.

3. **Prinsip Hak Akses Minimal Kontainer (*Least Privilege*):**
   - Pastikan aplikasi web berjalan di bawah akun pengguna non-root dengan perizinan sistem berkas *read-only* pada berkas sensitif yang tidak memerlukan modifikasi dinamis.
