---

## Problem Statement & Scope
Biner `gauntlet` (x86-64, non-PIE, `GNU_STACK` RWE = stack executable)
via `nc xebec/chatelaine.cylabacademy.net <port>`: baca 1000 B ke heap,
`printf(buf)` (format-string), baca lagi, `strcpy` ke buffer stack 112 B,
lalu return. Flag mentah di `flag.txt` (cwd). Tantangan: ASLR mengacak
alamat stack — exploit harus membocorkan alamat lalu kembali ke shellcode.

---

## Teori & Akar Kerentanan (Root Cause Theory)
1. **Format-string leak (CWE-134):** `printf(buf)` mengeksekusi `%p` dari
   input line-1, membocorkan puluhan alamat stack/libc/heap per koneksi.
2. **Stack overflow via `strcpy` (CWE-121):** `strcpy(rbp-0x70, heap)` tanpa
   batas; RIP di `buf+120`. `strcpy` berhenti di NUL pertama — alamat stack
   `0x7fff...` hanya punya NUL di 2 byte tinggi, sehingga 6 byte rendah RIP
   tetap tertulis dan 2 byte tinggi asal (sudah `00 00`) melengkapinya.
3. **Stack executable:** `GNU_STACK RWE` memperbolehkan lompat ke shellcode
   di awal buffer (teknik 126-style: `SC + pad + ret`).
4. **Kalibrasi offset:** leak menyediakan nilai stack `S` (slot setelah
   anchor `0x4011b6`); `buf = S - D` dengan `D` konstan per build. Nilai
   `S`/`buf` terikat frame yang sama sehingga `D` stabil lintas ASLR.

---

## Rekonstruksi Eksploitasi Step-by-Step
1. Launch instance (PUT `/api/challenges/143/instance/`); unduh `gauntlet`.
2. Analisis lokal (`objdump`): `lea rax,[rbp-0x70]` + `strcpy` + `leave/ret`
   → buf 112 B, RIP di +120; `checksec`: EXEC + `GNU_STACK RWE`.
3. Kalibrasi lokal via gdb: input 150×`B` → RBP/RIP `0x42..`, crash di
   `ret`; dump stack menempatkan `buf = S - 0x188` (biner lokal).
4. Sweep live `D` di sekitar teori (satu koneksi per nilai, jeda 2 dtk —
   paralelisme agresif memicu reset/firewall): **D=0x196 PWNED** (build lab
   ≠ build unduhan, offset bergeser 14 B — toleransi sweep menutupnya).
5. `ret = S - 0x196`; payload `SC(27B execve /bin/sh, null-free) + pad +
   ret`; kirim `cat flag*` → `e78e7bce9bd41d8acee927343d9d6ba4`.

## Takeaway Kompetensi LKS & Mitigasi Defensif
- **Jangan `printf(input)`:** gunakan `printf("%s", buf)`; format-string =
  primitif baca memori + (dengan `%n`) tulis memori.
- **Ganti `strcpy`:** `strncpy`/`strlcpy`/`memcpy` berukuran; aktifkan
  canary (`-fstack-protector`), NX stack, PIE + ASLR penuh.
- **Kalibrasi lokal-dulu:** bedah offset di biner unduhan (gdb/core dump),
  lalu sweep sempit di lab live; hindari brute force paralel brutal yang
  men-DoS lab sendiri dan memicu rate-limit.
