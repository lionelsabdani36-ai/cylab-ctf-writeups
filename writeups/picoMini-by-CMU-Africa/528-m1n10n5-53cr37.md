## Teori & Akar Kerentanan (Root Cause Theory)

1. **Struktur Paket Aplikasi Android & Kerapuhan Penyimpanan Sumber Daya (CWE-312):**
   Aplikasi Android didistribusikan dalam format arsip ZIP terkompresi (.apk). Seluruh string antarmuka pengguna dikompilasi oleh Android Asset Packaging Tool (AAPT2) ke dalam tabel biner `resources.arsc`. Pengembang pemula sering berasumsi bahwa kompilasi biner sumber daya setara dengan enkripsi yang aman. Nyatanya, utilitas rekayasa balik modern seperti `apktool` dan `jadx` dapat merekonstruksi berkas `res/values/strings.xml` menjadi teks XML asli dalam hitungan detik.

2. **Penggunaan Enkode Statis Sebagai Pengganti Enkripsi Kriptografis (CWE-798 / CWE-327):**
   Pada berkas XML antarmuka `res/layout/activity_main.xml`, elemen TextView menampilkan label teks merujuk pada resource ID `@string/banana_secret` atau `@string/Banana`. Pada berkas `res/values/strings.xml`, atribut tersebut menyimpan string biner terenkode:
   ```xml
   <string name="Banana">MFRWCZDFNV4XWMLUL53TI43OG5PWQNDSMRPXK3TSGR3DG3BRNY4V65DIGNPW2MDCGFWDGX3DGBSDG7I=</string>
   ```
   Pengembang mengandalkan skema *Security through Obscurity* dengan mengaburkan string rahasia menggunakan pengkodean Base32 RFC 4648 tanpa proteksi kunci kriptografis asimetris atau derivasi runtime.

3. **Spesifikasi Base32 RFC 4648:**
   Algoritma Base32 memetakan blok 5 bit ke dalam alfabet 32 karakter standar (`A-Z` dan `2-7`). Karena tidak membutuhkan salt maupun kunci rahasia, representasi ini bersifat deterministik penuh dan dapat diinversi secara instan oleh analis keamanan tanpa mengeksekusi aplikasi.

## Rekonstruksi Eksploitasi Step-by-Step

1. **Dekompilasi Berkas APK:**
   Ekstrak dan dekompilasi seluruh aset paket `app.apk` menggunakan APKTool:
   ```bash

   ```
   Atau gunakan JADX untuk membaca struktur proyek Java dan manifest:

3. **Ekstraksi Ciphertext dari Kamus Sumber Daya:**
   Buka berkas `decompiled_minion/res/values/strings.xml`:
   ```bash
   grep -i "banana" decompiled_minion/res/values/strings.xml
   ```

4. **Eksekusi Dekode Base32 Melalui Python:**

## Takeaway Kompetensi LKS & Mitigasi Defensif

Pada uji kompetensi LKS Cyber Security Nasional bidang *Mobile Application Defense & Hardening*:
1. **Penerapan R8 / ProGuard & Resource Shrinking:**
   Wajib mengonfigurasi `minifyEnabled true` dan `shrinkResources true` pada `build.gradle` Android untuk memangkas dan mengaburkan metadata sumber daya yang tidak dipanggil secara publik.
2. **Eliminasi Hardcoded Secrets pada Client-Side (OWASP MASVS-STORAGE):**
   Data rahasia, token verifikasi, atau kunci autentikasi tidak boleh disimpan di sisi klien (baik pada XML sumber daya, SharedPreferences, maupun bytecode DEX). Rahasia harus diisolasi di backend server dan hanya diberikan setelah autentikasi pengguna berhasil melalui TLS mutual pinning (mTLS).
3. **Pemanfaatan Android Keystore & Native C/C++ (JNI):**
   Jika aplikasi membutuhkan penyimpanan token lokal, enkripsi wajib dilakukan menggunakan kunci yang dihasilkan oleh hardware-backed Android Keystore (KeyStore API) atau disimpan di pustaka biner native (`.so`) yang di-strip simbol debugging-nya untuk mempersulit inspeksi statis oleh penyerang.
