## Problem Statement & Scope
Diberikan berkas paket aplikasi Android (`app.apk`). Peserta diminta membongkar kode dan sumber daya aplikasi untuk menemukan flag rahasia.

---

## Teori & Akar Kerentanan (Root Cause Theory)
1. **Unprotected Android Resources:** String rahasia tersimpan di dalam tabel sumber daya biner `resources.arsc` dengan enkripsi sederhana (Base32).
2. **Ketiadaan Obfuskasi:** Kode Smali/DEX dan layout XML dapat didekompilasi dengan mudah menggunakan `jadx` atau `apktool`.

---

## Rekonstruksi Eksploitasi Step-by-Step
1. Dekompilasi APK menggunakan `jadx app.apk` atau `apktool d app.apk`.
2. Periksa `activity_main.xml` dan temukan referensi string `Banana`.
3. Buka entri string di `res/values/strings.xml` yang berisi ciphertext Base32.
4. Decode Base32 untuk memulihkan flag resmi.
