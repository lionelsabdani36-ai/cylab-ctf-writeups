#### MODUL MOD-01: Chall 481 (flags are stepic) - Forensics / Spatial Domain Steganography
- Target Platform: CyLab Security Academy / picoCTF 2025
- Kategori: Digital Forensics / Image Steganography & Spatial Domain LSB Decoding
- Bobot: 100 Poin | Status: VERIFIED & SOLVED
- Flag Resmi: academy{fl4g_h45_fl4g4fd6a57e}
- Standar Kepatuhan: NIST SP 800-115 Bagian 4.2, RFC 2083 (PNG), CWE-532, CWE-319

1. First Principles & Anatomi Steganografi Spasial LSB:
   Representasi citra bitmap 24-bit TrueColor atau 32-bit RGBA menyimpan intensitas warna setiap piksel dalam saluran komponen terpisah (Red, Green, Blue, Alpha). Setiap saluran warna direpresentasikan oleh 1 byte data (8 bit) dengan rentang nilai skalar 0 hingga 255.
   Pada domain spasial, modifikasi pada bit bobot terendah (Least Significant Bit / bit ke-0) hanya mengubah nilai skalar intensitas sebesar +1 atau -1. Secara fotometri, deviasi kontras dan luminansi ini bernilai kurang dari 0.4%, berada jauh di bawah ambang batas persepsi visual manusia (Just Noticeable Difference / JND). Celah persepsi biologis inilah yang dimanfaatkan untuk menyembunyikan payload biner rahasia.

2. Dekonstruksi Protokol Penyandian Pustaka `stepic`:
   Pustaka steganografi Python `stepic` menerapkan protokol pemetaan bit yang unik. Alih-alih menyematkan 1 bit per piksel atau 3 bit per piksel (1 bit per saluran RGB) secara langsung, `stepic` memetakan tepat 1 byte karakter (8 bit data) ke dalam 3 piksel konsekutif yang menghasilkan 9 saluran subpiksel warna:
   - Saluran subpiksel 0 s.d. 6: Menyimpan bit data urutan 7 s.d. 1 dari byte karakter secara berurutan.
   - Saluran subpiksel 7: Menyimpan bit data urutan 0 (LSB dari karakter).
   - Saluran subpiksel 8: Berfungsi sebagai bit kontrol terminasi pesan (EOF Flag).
     Jika `pixels[8] & 1 == 0`, aliran data berlanjut ke karakter berikutnya.
     Jika `pixels[8] & 1 == 1`, karakter saat ini adalah karakter terakhir dari pesan rahasia (terminasi aliran).

   Formula matematika rekonstruksi 1 byte karakter dari 9 saluran subpiksel:
   Byte = sum_{c=0}^{7} ((pixels[c] & 1) << (7 - c))

3. Tantangan Rekayasa Skala Besar (Decompression Bomb Handling):
   Pada berkas tantangan `flags/upz.png` (entitas fiktif Upanzi), citra memiliki dimensi masif 14173 x 10630 piksel, yang setara dengan lebih dari 150 juta piksel (150 megapiksel). Pustaka pengolah citra standar seperti Pillow secara default membatasi resolusi maksimum (sekitar 89 megapiksel) untuk mencegah serangan Denial of Service berbasis kompresi (Decompression Bomb / Pixel Flood DoS).
   Untuk menganalisis bukti forensik ini tanpa kegagalan sistem:
   - Nonaktifkan batas ambang Pillow: `Image.MAX_IMAGE_PIXELS = None`.
   - Gunakan iterator streaming `iter(im.getdata())` alih-alih memuat seluruh array citra ke dalam struktur list memori sekaligus. Karena pesan tersembunyi disisipkan mulai dari piksel pertama (offset 0), kita hanya perlu membaca beberapa ratus piksel awal sebelum mencapai bit kontrol penutup (EOF).

4. Rekonstruksi Ekstraksi Bitwise Python:
```python
from PIL import Image

Image.MAX_IMAGE_PIXELS = None
im = Image.open('upz.png')
imdata = iter(im.getdata())

recovered_chars = []
while True:
    # Ambil 3 piksel konsekutif, abaikan kanal Alpha jika ada
    p1 = next(imdata)[:3]
    p2 = next(imdata)[:3]
    p3 = next(imdata)[:3]
    channels = list(p1 + p2 + p3)

    # Rekonstruksi 1 byte karakter dari 8 kanal pertama
    char_val = 0
    for c in range(7):
        char_val |= (channels[c] & 1)
        char_val <<= 1
    char_val |= (channels[7] & 1)
    recovered_chars.append(chr(char_val))

    # Periksa bit terminasi EOF pada kanal ke-9
    if channels[8] & 1:
        break

flag = ''.join(recovered_chars)
print('[+] Recovered Flag:', flag)
```

#### MODUL MOD-03: Chall 479 (quantum scrambler) - Reverse Engineering / Deterministic Deobfuscation
- Target Platform: CyLab Security Academy / picoCTF 2025
- Kategori: Reverse Engineering / Algorithm Deobfuscation & Permutation Reversal
- Bobot: 200 Poin | Status: VERIFIED & SOLVED
- Flag Resmi: academy{qu4ntum_unscr4mbl3d_r3v3rs3_479}
- Standar Kepatuhan: NIST SP 800-115 Bagian 4.2, NIST FIPS 197, CWE-327

1. First Principles Kriptografi vs Obfuskasi Deterministik:
   Kriptografi sejati menuntut dua sifat mutlak yang dirumuskan oleh Claude Shannon: Konfusi (Confusion) dan Difusi (Diffusion). Konfusi mengaburkan hubungan antara teks terang dan teks tersandi (biasanya melalui substitusi non-linier / S-Box), sedangkan Difusi menyebarkan pengaruh satu bit teks terang ke banyak bit teks tersandi.
   Pada tantangan ini, klaim algoritma quantum scrambling hanyalah jargon penyamaran (security through obscurity / CWE-327). Setiap karakter teks terang c_i dikonversi ke nilai heksadesimal `hex(ord(c_i))` tanpa penambahan kunci acak, tanpa operasi bitwise satu arah, dan tanpa difusi matematis. Hubungan antara masukan dan keluaran adalah pemetaan satu-satu (bijeksi).

2. Struktur Data Bersarang & Artefak Indeks:
   Algoritma pembungkus membungkus elemen data ke dalam struktur list Python bersarang:
   `scrambled_list.append([item[0], [hex(i)]])`
   Di mana `i` adalah indeks posisi iterasi pembungkus, dan `item[0]` menyimpan nilai heksadesimal karakter asli. Karakteristik yang membedakan byte flag dengan artefak indeks:
   - Byte karakter teks flag memiliki representasi heksadesimal dari nilai ASCII karakter tercetak (karakter yang valid berada pada interval desimal 32 <= val <= 126, seperti huruf 'a' = 0x61, '{' = 0x7b, dst).
   - Penelusuran hierarki struktur list secara rekursif atau traversal linier memungkinkan penyaringan token heksadesimal yang merepresentasikan karakter flag.

3. Rekonstruksi Aman dengan Abstract Syntax Tree (AST):
   Banyak peserta pemula menggunakan fungsi bawaan `eval()` untuk membaca representasi string list Python. Praktik ini sangat berbahaya dalam audit forensik karena jika berkas berisi payload berbahaya (seperti `__import__('os').system(...)`), peranti analisis analis siber dapat terkompromi (CWE-95 / Code Injection).
   Standar baku rekayasa siber mewajibkan penggunaan parser statis aman `ast.literal_eval`.

4. Skrip Pemulihan Deterministik Python:
```python
import ast

with open('scrambled.txt', 'r', encoding='utf-8') as f:
    raw_content = f.read().strip()

# Parsing struktur data secara aman tanpa evaluasi kode dinamis
data_tree = ast.literal_eval(raw_content)

def extract_hex_tokens(node):
    tokens = []
    if isinstance(node, list):
        for child in node:
            tokens.extend(extract_hex_tokens(child))
    elif isinstance(node, str) and node.startswith('0x'):
        tokens.append(node)
    return tokens

all_tokens = extract_hex_tokens(data_tree)

# Filter dan konversi byte ASCII tercetak
flag_chars = []
for token in all_tokens:
    val = int(token, 16)
    if 32 <= val <= 126:
        flag_chars.append(chr(val))

recovered_flag = ''.join(flag_chars)
print('[+] Flag Terpulihkan:', recovered_flag)
```

### 5. PANDUAN REMEDIASI DEFENSIF BLUE TEAM BERSTANDAR NIST SP 800-115

Sebagai calon juara LKS Cyber Security, kalian tidak hanya dituntut mampu mengeksploitasi sistem (Red Team), tetapi wajib menguasai prinsip perlindungan dan remediasi arsitektur sistem (Blue Team). Berikut adalah panduan remediasi defensif berstandar industri:

1. Remediasi Steganografi & Saluran Komunikasi Terselubung (NIST SP 800-115 §4.2, NIST SP 800-53 SI-7, SI-10):
   - Content Disarm and Reconstruction (CDR): Gateway aplikasi web wajib menerapkan pembersihan citra aktif. Sebelum aset grafis disimpan atau dipublikasikan, sistem harus melakukan normalisasi spasial atau transkoding lossy terkontrol (misalnya mengubah format citra menjadi WebP dengan kualitas 90% atau re-encoding PNG terkompresi ulang). Proses kuantisasi ini secara otomatis menghancurkan informasi bit pada saluran LSB tanpa merusak tampilan visual.
   - Pemeriksaan Entropi Spasial & Deteksi RS: Terapkan sistem pendeteksi saluran terselubung menggunakan analisis statistik Chi-Square dan Sample Pair Analysis pada bit plane terendah citra untuk mendeteksi deviasi distribusi bit acak yang tidak wajar.
   - Penegakan Batasan Dimensi Citra: Terapkan batasan resolusi piksel maksimum (misalnya maksimal 4096 x 4096 piksel) pada level reverse proxy (Nginx) untuk mencegah serangan konsumsi sumber daya (Decompression Bomb / Pixel Flood DoS).

2. Remediasi Arsitektur Protokol WebSocket Real-Time (RFC 6455, NIST SP 800-53 AC-3, SC-7, NIST SP 800-218):
   - Validasi State Machine Otoritatif Sisi Server: Server backend wajib menjadi satu-satunya otoritas yang menentukan status logika bisnis (Truth Authority). Klien hanya diizinkan mengirimkan input aksi dasar (misalnya notasi langkah 'e2e4'), sementara verifikasi legalitas langkah, pembaruan posisi papan FEN, dan penentuan kondisi kemenangan (checkmate) wajib dikalkulasi secara eksklusif oleh server. Jangan pernah menerima properti penentu status seperti {'status': 'win'} dari klien!
   - Skema Validasi Pesan Ketat (Message Schema Enforcement): Gunakan validator skema formal seperti JSON Schema atau Protocol Buffers pada setiap frame WebSocket yang masuk. Setiap frame yang memuat kunci di luar spesifikasi yang diizinkan wajib langsung ditolak dan koneksi ditutup secara paksa.
   - Perlindungan Cross-Site WebSocket Hijacking (CSWSH): Pada saat jabat tangan HTTP Upgrade berlangsung, server wajib memvalidasi header `Origin` terhadap whitelist domain resmi dan memverifikasi token sesi anti-CSRF atau tiket otentikasi unik satu kali pakai (one-time ticket).

3. Remediasi Kriptografi Aman & Sanitasi Parsing Data (NIST FIPS 197, NIST SP 800-175B, CWE-327, CWE-95):
   - Larangan Keras Algoritma Kriptografi Buatan Sendiri: Hindari penggunaan algoritma permutasi deterministik atau obfuskasi buatan sendiri untuk melindungi data sensitif (CWE-327). Wajib menerapkan cipher simetris terautentikasi standar industri yang telah diuji secara formal, seperti AES-256-GCM atau ChaCha20-Poly1305.
   - Manajemen Kunci Kriptografi Tangguh: Gunakan fungsi pembentukan kunci standar industri seperti HKDF (RFC 5869) atau Argon2id dengan nilai salt acak minimal 128 bit.
   - Deserialisasi Data Statis Terisolasi: Dalam penanganan struktur data serialisasi, larang keras penggunaan rutin eksekusi kode dinamis seperti `eval()` atau `pickle.loads()`. Gunakan parser sintaks statis aman seperti `ast.literal_eval` atau parser JSON standar yang kebal terhadap serangan deserialisasi arbitrer.

Formula Matematis 3PL:
P_i(theta) = c_i + (1 - c_i) / (1 + exp(-a_i * (theta - b_i)))

Keterangan Notasi:
- theta: Estimasi kemampuan laten siswa (rentang skala standar -3.00 s/d +3.00).
- a_i: Parameter diskriminasi / daya pembeda soal terhadap tingkat penguasaan konsep.
- b_i: Parameter tingkat kesulitan soal pada skala laten.
- c_i: Parameter pseudo-guessing (peluang menjawab benar karena tebakan acak semu).
