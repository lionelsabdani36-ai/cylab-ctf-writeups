### 3. DEKONSTRUKSI MATEMATIS & ANALISIS FIRST PRINCIPLES TIAP MODUL

#### Modul 1: Chall 473 Guess My Cheese (Part 1) (Applied Cryptography & Linear Inversion)
1. **Struktur Aljabar Modulo 26:**
   Transformasi affine E(x) = (ax + b) mod 26 memetakan indeks karakter alfabet [0..25]. Agar fungsi bersifat bijektif, pengali a harus memiliki balikan modular gcd(a, 26) = 1. Terdapat tepat 12 elemen yang memenuhi, sehingga ruang kunci pasangan (a, b) hanya berjumlah 312 kombinasi.
2. **Kriptanalisis Chosen-Plaintext Attack (CPA):**
   Dengan mengirimkan keju yang diketahui Asiago, karakter pertama 'A' (x = 0) menghasilkan karakter sandi E(0) = b mod 26. Parameter b langsung terungkap tanpa komputasi tambahan. Karakter kedua 's' (x = 18) membentuk persamaan kongruensi 18a + b = y1 mod 26 yang diselesaikan melalui reduksi modulo 13, menghasilkan nilai unik a. Nilai balikan modular a^(-1) memulihkan keju target secara deterministik.

#### Modul 2: Chall 472 Flag Hunters (Software Security & Interpreter Control Flow)
1. **Model Mesin Status dan Pointer Instruksi:**
   Interpreter lyric-reader.py memandu eksekusi lagu melalui pointer baris lip. Karena baris intro rahasia berada pada indeks 0..3 dan program menginisialisasi lip pada baris ke-14, alur default tidak pernah menjangkau token flag.
2. **Pencemaran Memori Kode via Delimiter Injection (CWE-74 / CWE-94):**
   Pada prompt penonton refrein, program menerima masukan teks mentah dan menyimpannya langsung ke dalam larik instruksi aktif song_lines tanpa sanitasi karakter titik koma (;). Menyuntikkan payload ;RETURN 0 memutasi baris refrein menjadi instruksi lompatan baru. Ketika bait berikutnya memanggil refrein, interpreter memproses token RETURN 0 dan memaksa pointer lip kembali ke baris ke-0, mencetak flag secara langsung.

### 4. MITIGASI DEFENSIF & STANDAR PENGUATAN BLUE TEAM

1. **Penghentian Cipher Klasik & Migrasi ke Standar Modern (FIPS 140-3):**
